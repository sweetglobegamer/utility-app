# Utility App

Native Android app (Kotlin, XML/Views, Room, fully offline). Target SDK 36 (Android 16), min SDK 26.

Currently has: Notepad (add, edit, long-press to delete).

## Build the APK with GitHub Actions
1. Push this project to a GitHub repo (branch `main`).
2. Open the repo's **Actions** tab, open the latest "Build APK" run.
3. Download the **app-debug-apk** artifact (a zip containing `app-debug.apk`).
4. Copy the APK to your phone and install it.
